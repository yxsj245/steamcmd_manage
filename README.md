# 项目介绍
一个专注于WindowsSteamcmd的一键快速开服脚本和管理 \
![image](https://github.com/user-attachments/assets/6d98594b-d274-4465-afc0-9b3a4628dbad)
# 已支持功能
- [x] 自动安装steamcmd
- [x] 通过appid快速下载服务端
- [x] 对接[MCSManager](https://www.mcsmanager.com/)
- [x] 常用服务端快速部署，现已支持超过20款游戏
- [x] 自动安装环境依赖
- [x] 启动服务端持续检测已申请开通的端口

# 如何使用
从 [Releases](https://github.com/yxsj245/steamcmd_manage/releases)中下载最新发行版exe，然后创建一个单独的英文名文件夹然后双击运行即可自动安装steamcmd。
